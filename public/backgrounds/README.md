# Background Presets

This folder holds background images that streamers can choose from.
To allow a preset, place the corresponding image in this folder:

- `cosmic.jpg` (Cosmic Dust theme)
- `sunset.jpg` (Sunset Breeze theme)
- `neon.jpg` (Neon Cyber theme)
- `aurora.jpg` (Aurora Borealis theme)
- `ocean.jpg` (Ocean Wave theme)
